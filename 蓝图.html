v2 · 商业 API 简化路线

3D 导演台 · 单 RGB 粗略视频参考路线

基于 策划 001（JSON SSOT + 自校验） 的整合方案。v2 简化：砍掉 ComfyUI 自建， 视频模型只用商业 API（可灵 / 火山 / 海螺 / Veo），导出单 RGB 颜色形状区分的 mp4。

v2 决策： 视频模型入口 ComfyUI 自建 + Wan2.1 + CameraCtrl → 商业 API 远程调用； 导出通道 RGB + Depth + Normal + Seg 四通道 → 单 RGB · 颜色形状区分。 砍掉 GPU / 模型权重 / 容器维护，上线更快、零运维、模型自动升级。
● 仅 Web 浏览器/ ● 自研/ ● 单 RGB 粗略参考视频/ ● 商业 API 调度/ ● 4 周 MVP
§01

一句话定位

3D 导演台 = 视频模型的前置确定性分镜工具

不替代视频模型，只做"前置分镜"。导演一句话，AI 搭场景排运镜，导演微调确认，浏览器导出颜色形状区分的 mp4 粗略视频喂给可灵等商业 API，拿到最终视频。零自建、零 GPU、零运维。

§02

v1 → v2 · 简化前后对比

核心简化 = 砍 ComfyUI + 砍多通道渲染。整个产品轻一半，但 90% 用例不受影响。

§04

粗略视频规范 · 颜色形状区分

导演台输出的 mp4 长什么样。越简单越好——粗略视频是给视频模型的"运动信号"，不是给导演看的成品。

元素规则为什么
角色胶囊体 + 不同纯色（红 #e74c3c / 蓝 #3498db / 绿 #2ecc71 / 黄 #f1c40f）+ Mixamo 动画（站/走/跑/坐）模型能清晰区分主体；纯色不污染视觉风格
环境几何体（box / sphere / cylinder）+ 纯色 + 简单方向光不带 PBR / 不带纹理，避免细节污染
地面单色 plane + 简单网格（可选）给模型空间感
运镜6 个模板（push_in / pull_out / orbit / crane_up / tracking / static）+ CatmullRom 平滑模板化保证稳定性
帧率24fps商业视频模型通用帧率
时长用户可自定义 · 1-30s · 硬约束导演按镜头需求设；最长 30s（商业 API 单次生成上限）· 超 30s 不做拼接
分辨率720p（1280×720）或 1080p（1920×1080）模型接口常用规格
画面比例2.76:1 · Ultra Panavision 70早期 70mm 宽幅（《阿拉伯的劳伦斯》《2001 太空漫游》原始版）
2.39:1 · Scope / Anamorphic现代电影主流（《沙丘》《银翼杀手 2049》《奥本海默》）
2.00:1 · IMAX 增强IMAX 数字影厅 / Netflix 顶级剧集（《怪奇物语》《1899》）
1.85:1 · Flat北美院线标准宽银幕（绝大多数好莱坞剧情片）
16:9 (1.78:1)HDTV / 流媒体主流（B站 / YouTube / 优爱腾）
4:3 (1.33:1) · Academy早期学院标准 / 复古艺术片 / Wes Anderson（《布达佩斯大饭店》）
9:16短视频 / 移动端（抖音 / Reels / TikTok / 视频号）
1:1社交方形（Instagram / 小红书）
编码H.264 MP4，yuv420p兼容性最强
通道单 RGB（不要深度 / 法线 / 分割）商业 API 主要吃 RGB
音频无视频模型只生成视频
§05

v2 简化架构

浏览器做全部用户交互 + mp4 导出，后端只做视频模型 API 调度 + 自校验。

浏览器端做 3D 渲染 + 导演交互 + 单 RGB 视频导出，后端只做商业 API 调度 + 自校验。零 GPU、零模型、零容器。

关键技术决策 · v2

每个决策都给推荐 + 理由 + 替代方案。v2 简化项已标绿。

维度推荐理由替代方案

§10

风险与对策 · v2

砍掉 ComfyUI 自建风险，新增商业 API 相关风险。

风险概率影响对策
视频模型不严格遵循参考 v2 重点高高准备 3-5 个备选镜头让导演重抽；提供"参考强度"滑杆；多模态自校验抓早期失败
商业 API 输出与参考不一致高中Dispatcher 自动重试 + 缓存 + 多模型 failover
WebCodecs 浏览器兼容 v2 缓解低中MediaRecorder 兼容性 > WebCodecs（Firefox 也支持）；零特殊依赖
Web 端性能瓶颈中中限制物体 < 50；InstancedMesh；预览分辨率 720p
LLM 场景不合理（穿模）中中模板库 + Agent 工具层 AABB 碰撞检测 + 约束规则
商业 API 限流 / 慢 / 贵 v2 新增高中任务队列 + 缓存首帧图；多模型 failover；按调用付费预估上限
角色动画质量低中中MVP 用 Mixamo 通用动画库；不上手动 K 帧
ComfyUI 自建成本 删除——v2 已消除 · 零 GPU / 零模型 / 零容器
LLM 调用成本失控中中首屏用小模型（Haiku / GPT-4o-mini）生成模板选择，复杂对话用大模型
商业 API 接口变更 v2 新增中中Dispatcher 适配器隔离变化；版本化适配器；2-3 家备选
